# Sarabun for PDF documents

Unmodified Regular (400) and Bold (700) fonts from [Google Fonts](https://github.com/google/fonts/tree/88058c714073e72bb1b32baffc2d4ce9bc73944c/ofl/sarabun), commit `88058c714073e72bb1b32baffc2d4ce9bc73944c`.

Distributed under the SIL Open Font License 1.1; see [OFL.txt](./OFL.txt).
These keep the existing PDF font family available without depending on expired Google CDN version URLs. Vite emits them as separate assets; they are used only by the dynamically loaded PDF feature.
