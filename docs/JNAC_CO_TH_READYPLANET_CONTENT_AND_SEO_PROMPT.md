เอกสารนี้เป็น Prompt พร้อมใช้งานสำหรับสั่ง Codex เข้าไปปรับปรุงเว็บไซต์
https://www.jnac.co.th/ ผ่านระบบ ReadyPlanet ที่มีการ Login ผู้ดูแลไว้แล้ว

## วิธีใช้

1. เปิด Browser ที่ Login ReadyPlanet ของ JNAC.co.th ไว้แล้ว
2. คัดลอกข้อความในหัวข้อ **Prompt สำหรับ Codex** ทั้งหมด

## อำนาจที่ได้รับ

คุณได้รับอนุญาตให้แก้ไขและ Publish ได้ทันที โดยไม่ต้องขออนุมัติรายหน้า สำหรับ:

- ข้อความเดิมทุกหน้า
- รายละเอียดสินค้า หมวดสินค้า และบทความ
- SEO Title, Meta Description, Heading, Alt Text และ Internal Link
- ข้อความในเมนู Footer CTA และปุ่มลิงก์
- Font ขนาดตัวอักษร ระยะบรรทัด สีข้อความ และ Theme ผ่านการตั้งค่ามาตรฐานของ ReadyPlanet
- FAQ ตารางสเปก ตารางเปรียบเทียบ และเนื้อหาเชิงความรู้
- Schema หรือ Open Graph เฉพาะเมื่อ ReadyPlanet มีช่องตั้งค่ามาตรฐานที่ปลอดภัย

อย่าหยุดแค่เสนอแผน ให้สำรวจ แก้ไข Publish และตรวจหน้าสาธารณะจริงจนจบงาน

## ข้อห้ามเด็ดขาด

ห้ามทำสิ่งต่อไปนี้:

1. ห้ามลบชื่อสินค้า ชื่อหมวดสินค้า รุ่นสินค้า รหัสสินค้า หัวข้อสินค้า หรือ URL เดิม
2. ห้ามลบรูปภาพสินค้า รูปภาพบทความ แกลเลอรี ไฟล์ หรือรูปโลโก้เดิม
3. ห้ามเปลี่ยนสินค้าจากรุ่นหนึ่งเป็นอีกรุ่นหนึ่ง หรือทำให้ชื่อรุ่น/รหัสสินค้าเปลี่ยนความหมาย
4. ห้ามแต่งสเปกสินค้า คุณสมบัติ มาตรฐาน ใบรับรอง ราคา สต๊อก การรับประกัน หรือ Claim เชิงเทคนิคที่ไม่มีข้อมูลยืนยัน
5. ห้ามลบหน้า บทความ หมวดสินค้า เมนู ฟอร์มสั่งซื้อ ลิงก์เดิม หรือข้อมูลติดต่อ
6. ห้ามเปลี่ยน Domain, DNS, SSL, Hosting, แพ็กเกจ ReadyPlanet, วิธีชำระเงิน, Analytics, Tracking, สิทธิ์ผู้ใช้ หรือค่าใช้จ่ายใด ๆ
7. ห้ามเปลี่ยน URL Slug, Redirect, Canonical, robots.txt หรือ Sitemap แบบกระทบทั้งเว็บไซต์
8. ห้ามใส่ Keyword Spam, Hidden Text, Cloaking, เนื้อหาปั่นจำนวนมาก หรือ Schema ที่ไม่ตรงกับเนื้อหาจริง
9. ห้ามใช้ภาพ AI มาแทนรูปสินค้าจริง และห้ามลบ/เปลี่ยนรูปเดิมโดยไม่จำเป็น
10. ห้ามอ้างว่าการทำ SEO, Schema หรือ GEO รับประกันว่าจะติด Google AI Overview หรือถูก AI อ้างอิง

หากพบ CAPTCHA, OTP, Session หมดอายุ หรือสิทธิ์ไม่พอ ให้หยุดก่อนทำการแก้ไข และรายงานจุดที่ติดขัดอย่างชัดเจน ห้ามขอ บันทึก หรือเปิดเผยรหัสผ่าน

## หลักฐานและแหล่งข้อมูลที่ใช้เขียน

ก่อนเขียนใหม่ในแต่ละหน้า ให้เก็บข้อเท็จจริงจากแหล่งต่อไปนี้ตามลำดับ:

1. ชื่อสินค้า รุ่น รหัส ข้อมูล และรูปภาพที่มีอยู่ในหน้านั้น
2. Catalogue, Datasheet, ป้ายสเปก หรือเอกสารสินค้าจริงที่มีอยู่ในเว็บไซต์
3. เอกสารทางการจากผู้ผลิต หากตรวจสอบได้
4. ข้อมูลที่เจ้าของเว็บไซต์ให้ไว้

ถ้าข้อมูลไม่พอ:

- เขียนเฉพาะสิ่งที่ยืนยันได้
- อย่าเดาสเปก
- อย่าใส่ช่องว่างหรือข้อความ TODO ต่อหน้าลูกค้า
- ใช้ CTA เช่น “สอบถามสเปกเพิ่มเติมกับทีม J NAC” แทน
- บันทึกรายการที่ต้องขอ Datasheet เพิ่มไว้ในรายงานสุดท้าย

## มาตรฐาน Font และการอ่านทั้งเว็บไซต์

ใช้ Font Family เดียวกันทั้งเว็บไซต์สำหรับ Headline, เนื้อหา, เมนู, ปุ่ม และ Footer ยกเว้นโลโก้ที่เป็นรูปภาพ

ใช้เฉพาะ Font ที่ตั้งค่าได้จาก ReadyPlanet:

1. เลือก Sarabun หากมี
2. หากไม่มี เลือก Noto Sans Thai
3. หากไม่มี ให้เลือก Font ไทยที่อ่านง่ายที่สุดในระบบ

มาตรฐาน:

- เนื้อหาบนมือถือควรอ่านง่าย ไม่น้อยกว่า 16px หากระบบรองรับ
- ใช้ระยะบรรทัดประมาณ 1.5–1.7
- H1 ต้องเด่นและมีเพียงหนึ่งหัวข้อหลักต่อหน้า
- H2/H3 ต้องเป็นลำดับเดียวกันทุกหน้า
- สีข้อความต้อง Contrast ชัดเจน
- หลีกเลี่ยงข้อความติดกันแน่น หัวข้อใหญ่เกิน หรือ Font หลายตระกูลปนกัน
- ตรวจหน้าแรก หน้าหมวดสินค้า หน้าสินค้า และบทความทั้ง Desktop และ Mobile ก่อนใช้ Global Font/Theme ใหม่

ห้ามใส่ CSS หรือ JavaScript เอง หากไม่มีช่องทางมาตรฐานที่ปลอดภัยใน ReadyPlanet

## Master Pattern: หน้าสินค้าทุกรุ่น

รักษาชื่อสินค้า รุ่น และรหัสเดิมไว้เป็นหัวข้อหลักของหน้า จากนั้นเรียบเรียงข้อความใหม่ให้ทุกหน้ามี Pattern เดียวกันตามลำดับนี้

### 1. ชื่อสินค้าเดิม

- คงชื่อสินค้า รุ่น รหัส และหมวดเดิม
- แก้ได้เฉพาะการจัดวรรคตอนหรือรูปแบบการแสดงผลที่ไม่ทำให้ความหมายเปลี่ยน

### 2. สรุปสินค้าแบบตอบตรงคำถาม

เขียน 2–4 ประโยคแรกให้ตอบ:

- สินค้านี้คืออะไร
- เหมาะกับงานประเภทใด
- เหมาะกับวัสดุใด
- จุดเด่นการใช้งานคืออะไร

### 3. คุณสมบัติเด่น

ใช้ Bullet ที่อ่านเร็ว โดยยึดข้อมูลจริง เช่น:

- ประเภทเม็ดขัดหรือวัสดุหลัก
- ลักษณะงานที่เหมาะสม
- ลักษณะผิวงานที่ช่วยให้ได้
- เครื่องมือที่ใช้ร่วมกันได้
- จุดเด่นที่ยืนยันได้จากข้อมูลสินค้า

### 4. ตารางสเปกสินค้า

ใช้ตารางรูปแบบเดียวกันทุกหน้า และแสดงเฉพาะข้อมูลที่ยืนยันได้:

| รายการ | รายละเอียด |
| --- | --- |
| รุ่น / รหัสสินค้า | |
| ประเภทสินค้า | |
| วัสดุเม็ดขัด / วัสดุหลัก | |
| ขนาด / เส้นผ่านศูนย์กลาง | |
| เบอร์ / Grit | |
| รูปแบบหลัง / รูยึด / แกน | |
| วัสดุชิ้นงานที่เหมาะสม | |
| การใช้งานแนะนำ | |
| ข้อควรระวัง | |

ไม่ต้องใส่แถวที่ไม่มีข้อมูลยืนยัน และห้ามกรอกข้อมูลแทนด้วยการคาดเดา

### 5. เหมาะกับงานอะไร

อธิบายการใช้งานจริง เช่น งานเหล็ก สแตนเลส ไม้ สี พลาสติก โมลด์ หรือชิ้นส่วนเครื่องจักร เฉพาะที่ตรงกับข้อมูลของสินค้านั้น

### 6. วิธีเลือกและวิธีใช้งานเบื้องต้น

เพิ่มคำแนะนำที่ช่วยลูกค้าตัดสินใจ เช่น:

- เลือกเบอร์อย่างไร
- เลือกขนาดให้ตรงกับเครื่องมืออย่างไร
- เลือกตามวัสดุหรือชนิดงานอย่างไร
- ข้อควรระวังด้านความปลอดภัย

### 7. การเปรียบเทียบ

เพิ่มส่วนเปรียบเทียบเฉพาะเมื่อมีข้อเท็จจริงรองรับ เช่น:

- รุ่นนี้ต่างจากรุ่นที่เกี่ยวข้องอย่างไร
- Fiber Disc กับ Flap Disc เหมาะกับงานต่างกันอย่างไร
- จานทรายซ้อนหลังอ่อนกับหลังแข็งต่างกันอย่างไร
- กระดาษทรายหลังกาวกับหลังสักหลาดต่างกันอย่างไร
- เบอร์หยาบ กลาง และละเอียดเหมาะกับงานใด

ห้ามโจมตีสินค้า/แบรนด์คู่แข่ง และห้ามกล่าวอ้างผลลัพธ์เกินข้อมูลจริง

### 8. คำถามที่พบบ่อย

เพิ่ม FAQ ที่มองเห็นได้จริงบนหน้า 2–5 ข้อ โดยใช้คำถามที่ลูกค้าน่าจะถามและตอบจากข้อมูลจริง เช่น:

- สินค้านี้ใช้กับวัสดุอะไรได้บ้าง?
- ใช้กับเครื่องมือชนิดใด?
- ควรเลือกเบอร์ใดสำหรับงานนี้?
- ต่างจากรุ่นที่เกี่ยวข้องอย่างไร?
- มีขนาดหรือรุ่นอื่นหรือไม่?

### 9. สินค้าและความรู้ที่เกี่ยวข้อง

เพิ่ม Internal Link ไปยัง:

- สินค้ารุ่นใกล้เคียง
- หมวดสินค้าที่เกี่ยวข้อง
- บทความวิธีเลือกสินค้า
- jnac.online สำหรับดูสินค้าและสอบถามการสั่งซื้อ เมื่อเหมาะสม

### 10. CTA

ปิดท้ายด้วย CTA ที่ช่วยลูกค้าดำเนินการต่อ เช่น:

- ต้องการเลือกสินค้าให้เหมาะกับหน้างาน ติดต่อทีม J NAC
- ดูสินค้าและสอบถามการสั่งซื้อเพิ่มเติมที่ jnac.online
- ส่งรูปหน้างานหรือสเปกเดิมมาให้ทีมช่วยแนะนำได้

## Master Pattern: หน้าหมวดสินค้า

ทุกหมวดสินค้าต้องใช้โครงสร้างเดียวกัน:

1. H1 ชื่อหมวดเดิม
2. หมวดนี้คืออะไร
3. เหมาะกับงานและวัสดุประเภทใด
4. วิธีเลือกเบื้องต้น
5. ตารางเปรียบเทียบชนิดสินค้าในหมวด เมื่อมีข้อมูลจริง
6. หมวดย่อยและสินค้าที่เกี่ยวข้อง
7. FAQ ของหมวดสินค้า
8. บทความความรู้ที่เกี่ยวข้อง
9. CTA ไปสอบถามหรือไป jnac.online

## Master Pattern: บทความ

ห้ามลบบทความเดิมที่มีอยู่ ให้เรียบเรียงใหม่เพื่อให้เป็นรูปแบบเดียวกันและเป็นประโยชน์ต่อผู้อ่าน

1. H1 ชื่อบทความเดิม หรือปรับให้ชัดขึ้นโดยไม่เปลี่ยนความหมาย
2. คำตอบสรุปตรงประเด็นในช่วงต้น
3. อธิบายปัญหาหรือหลักการที่ลูกค้ากำลังค้นหา
4. ตารางเปรียบเทียบเมื่อมีหลายตัวเลือก
5. ขั้นตอนเลือกหรือใช้งาน
6. ข้อควรระวัง
7. FAQ
8. Internal Link ไปหมวดและสินค้าที่เกี่ยวข้อง
9. CTA ติดต่อ J NAC หรือไป jnac.online

ปรับหรือสร้างบทความความรู้คุณภาพสูงเมื่อมีข้อมูลเพียงพอ เช่น:

- Fiber Disc กับ Flap Disc ต่างกันอย่างไร
- จานทรายซ้อนหลังอ่อนกับหลังแข็ง เลือกอย่างไร
- กระดาษทรายขัดน้ำกับกระดาษทรายขัดแห้ง ต่างกันอย่างไร
- กระดาษทรายหลังกาวกับหลังสักหลาดต่างกันอย่างไร
- Aluminum Oxide, Zirconia และ Ceramic Abrasive ต่างกันอย่างไร
- วิธีเลือกเบอร์กระดาษทรายให้เหมาะกับชิ้นงาน
- วิธีเลือกใบตัดและใบเจียรให้เหมาะกับงานและปลอดภัย

ห้ามคัดลอกบทความจากเว็บไซต์อื่น ห้ามสร้างเนื้อหาที่ต่างกันเพียงเปลี่ยน Keyword และห้ามใช้ข้อมูลเทคนิคที่ไม่มีแหล่งอ้างอิง

## SEO, AI Search, AI Overview และ GEO

ทำเพื่อช่วยให้ระบบค้นหาและ AI เข้าใจข้อมูลจริงของหน้าเว็บ โดยให้ความสำคัญกับประโยชน์ของลูกค้าก่อนเทคนิค SEO

ทุกหน้าสำคัญต้องมี:

- SEO Title ที่ไม่ซ้ำ ชัดเจน และตรงกับเจตนาของหน้า
- Meta Description ที่อธิบายประโยชน์จริง ไม่ยัด Keyword
- H1 เดียว และ H2/H3 ตามลำดับ
- ย่อหน้าคำตอบหรือคำอธิบายช่วงต้นหน้า
- ตารางสเปกหรือเปรียบเทียบเมื่อเหมาะสม
- FAQ ที่ผู้ใช้มองเห็นจริง
- Alt Text ที่อธิบายรูปสินค้าเดิมตามความจริง
- Internal Link ที่มีความสัมพันธ์กับเนื้อหา
- CTA ที่ชัดเจนและไม่บังคับขาย

หาก ReadyPlanet รองรับ Schema ผ่านช่องทางมาตรฐาน ให้ใช้เฉพาะชนิดที่ตรงกับเนื้อหาจริง:

- Organization
- BreadcrumbList
- Product
- Article
- FAQPage เฉพาะ FAQ ที่แสดงบนหน้าเว็บจริง

ห้ามเพิ่ม llms.txt, ห้ามแก้ robots.txt หรือห้ามเปลี่ยนนโยบาย Crawler เช่น GPTBot, OAI-SearchBot หรือ Googlebot โดยไม่ได้รับอนุมัติเป็นลายลักษณ์อักษร

## การจัดการรูปภาพเดิม

- เก็บรูปภาพสินค้าและบทความเดิมทั้งหมด
- ห้ามลบ ห้ามแทนที่ และห้ามสร้างภาพใหม่เพื่อกลบภาพเดิม
- ปรับได้เฉพาะ Alt Text, Caption และตำแหน่งการแสดงผล เมื่อไม่กระทบรูปเดิม
- ใช้รูปสินค้าจริง ป้ายสเปกจริง และ Datasheet จริงเป็นแหล่งข้อมูลหลัก
- สำหรับภาพตกแต่งที่ไม่สื่อความหมาย ให้ใช้ Alt Text ตามหลัก Accessibility โดยไม่ยัด Keyword

## ลำดับการดำเนินงาน

1. สำรวจทุกหน้าและบันทึก Baseline
2. ปรับ Font และ Theme ให้ใช้มาตรฐานเดียวกันทั้งเว็บไซต์
3. ปรับหน้าแรก About Contact Menu และ Footer
4. ปรับทุกหมวดสินค้าตาม Master Pattern
5. ปรับหน้าสินค้าทุกรุ่นตาม Master Pattern
6. ปรับบทความเก่าและสร้างบทความเปรียบเทียบที่จำเป็น
7. ปรับ SEO Title Meta Description Alt Text และ Internal Link
8. Publish เป็นชุดเล็ก ๆ และเปิด Public URL ตรวจทันที
9. ตรวจหน้า Desktop และ Mobile ก่อนสรุปงาน

หาก ReadyPlanet Save และ Publish อัตโนมัติ ให้แก้ทีละหน้าและตรวจผลจริงทันที ห้ามแก้จำนวนมากโดยไม่ตรวจหน้า Public

## เกณฑ์การตรวจรับงาน

งานจะถือว่าเสร็จเมื่อ:

- ทุก Public URL ได้รับการตรวจและมีสถานะชัดเจน
- หน้าแรก หมวดสินค้า หน้าสินค้า และบทความ ใช้ Pattern เดียวกันตามประเภทของหน้า
- เนื้อหาที่ปรับไม่มีการแต่งสเปกหรือข้อเท็จจริง
- ชื่อสินค้า รุ่น รหัส หัวข้อสินค้า รูปภาพ และ URL เดิมยังอยู่ครบ
- เว็บไซต์ใช้ Font Family เดียวกันและอ่านง่ายทั้ง Desktop/Mobile
- SEO พื้นฐาน Internal Link Alt Text และ CTA สำคัญได้รับการปรับ
- ไม่มีความเสียหายต่อฟอร์ม การติดต่อ ราคา สต๊อก ระบบสั่งซื้อ หรือโดเมนเดิม
- ทุกชุดงานที่ Publish ได้รับการตรวจจาก Public URL จริง

## รูปแบบรายงานสุดท้าย

รายงานเป็นภาษาไทย กระชับ และห้ามกล่าวว่าเสร็จหากยังไม่ตรวจหน้าสาธารณะจริง

รายงานต้องมี:

1. จำนวนหน้าที่ตรวจทั้งหมด
2. จำนวนหน้าที่ปรับแล้ว คงเดิม และรอข้อมูล
3. Font และ Global Setting ที่เปลี่ยน
4. Pattern ที่นำไปใช้กับหน้าสินค้า หมวดสินค้า และบทความ
5. รายการ URL สำคัญที่แก้ พร้อมสรุปก่อน/หลัง
6. บทความที่ปรับหรือสร้างใหม่
7. ลิงก์และฟังก์ชันที่ตรวจแล้ว
8. รายการสินค้าที่รอ Datasheet หรือข้อมูลเพิ่ม
9. รายการที่ไม่ได้ทำ เพราะอยู่นอกอำนาจหรือจำเป็นต้องขออนุมัติจาก Boss jack
